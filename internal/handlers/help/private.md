This bot creates and manages promo codes for @DickGrowerBot.

Commands (admins only):
/promo — create a new promo code
/get — show the table of promo codes
/stats — full statistics for specific codes
/edit — change an existing promo code
/delete — delete an existing promo code
/help — show this message

In group chats the bot does nothing: all commands work in direct messages only. Promo codes themselves are redeemed in @DickGrowerBot, not here.
