Этот бот создаёт промокоды для @DickGrowerBot и управляет ими.

Команды (только для админов):
/promo — создать новый промокод
/get — показать таблицу промокодов
/stats — полная статистика по конкретным промокодам
/edit — изменить существующий промокод
/delete — удалить существующий промокод
/help — показать это сообщение

В группах бот ничего не делает: все команды работают только в личных сообщениях. Сами промокоды активируются в @DickGrowerBot, а не здесь.
